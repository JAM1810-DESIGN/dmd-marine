# DMD Marine Consultation & Services — Platform

A unified platform for DMD Marine Consultation & Services: corporate website, online booking, customer CRM, marine service management, admin business dashboard, Facebook Business integration, reporting & analytics, and notifications — one Next.js app, one PostgreSQL database, one authentication system.

> Independent Marine Expertise for Vessel Operations, Cargo Assurance, Compliance, and Maritime Professional Development.

## Status

Under active phased development. See `docs/specs/` for the original phase briefs and the plan history for execution reports.

## Stack

- **Frontend/Backend:** Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion
- **Database:** PostgreSQL via Prisma ORM
- **Auth:** Auth.js v5 (Credentials provider, JWT sessions) — internal staff roles only (Admin / Manager / Staff / Finance Officer). No customer accounts; booking is a public guest form.
- **Storage:** Cloudinary (receipts, attachments, media) — wired in a later phase
- **Email:** Resend — wired in a later phase
- **Package manager:** pnpm
- **Deployment:** Docker, Vercel-compatible

## Getting Started

Prerequisites: Node.js 20+, pnpm, Docker Desktop.

```bash
# 1. Install dependencies
pnpm install

# 2. Copy env config and fill in secrets
cp .env.example .env
# generate AUTH_SECRET with: openssl rand -base64 32

# 3. Start local Postgres
docker compose up -d

# 4. Run migrations and generate the Prisma client
pnpm db:migrate
pnpm db:generate

# 5. Seed a dev admin user (development only)
pnpm db:seed
# admin@dmdmarine.dev / DevAdmin123!

# 6. Start the dev server
pnpm dev
```

Visit `http://localhost:3000` for the public site and `http://localhost:3000/login` to sign in to the dashboard.

Other scripts: `pnpm build`, `pnpm lint`, `pnpm typecheck`, `pnpm db:studio` (Prisma Studio).

### Notes

- The dev Postgres container defaults to port `5435` (see `docker-compose.yml` / `.env.example`) to avoid clashing with other local Postgres instances on ports 5432–5434.
- `src/generated/prisma` is generated by `prisma generate` and is gitignored — regenerate it after pulling schema changes.
